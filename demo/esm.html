Dynamic datalist via esm.sh

This page loads the component class from esm.sh and registers it manually. See the README for the API.

Initial suggestions

The bootstrap attribute loads suggestions without waiting for typing. If the module or request fails, you can still enter a value. 

<dynamic-datalist endpoint="/api/demo" bootstrap>
  <label for="demo-input">Search</label>
  <input id="demo-input" name="demo" list="demo-options" />
  <datalist id="demo-options">
    <option>Popular option</option>
  </datalist>
</dynamic-datalist>
Choose a suggestion or type your own value.
